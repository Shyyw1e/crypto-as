# MVP: Admin панель

## Цель: управление доступом пользователей к боту

### Роли: пока что только `super_admin`

## Функции MVP:
- Найти пользователя по `chat_id`;
- Посмотреть статус доступа (`none | trial | active | expired | blocked`);
- Выдать trial вручную;
- Активировать подписку по дату;
- Заблокировать/разблокировать пользователя;
- Посмотреть историю действий админа;

### Что НЕ делаем в MVP:
- полноценный UI;
- автоматические платежи;
- multi-admin с разными правами;

#### API-формат: пока только внутренний HTTP + ADMIN_API_TOKEN
